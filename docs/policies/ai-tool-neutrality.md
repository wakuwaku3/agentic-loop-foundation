# AIツール非依存ポリシー

## 目的

このポリシーは、Agentic Loopが要求処理・コードベース自己診断・要求入力に用いるAIコーディングツール（CLI/Agent）の選定と統合に適用する。特定ベンダーのAIツールへロックインせず、差し替え可能に保つことで、契約・可用性・料金・品質の変化に追従できるようにする。

## 原則

- 特定のAIコーディングツールを前提とした実装・運用・ドキュメントに固定しない。少なくともCodex CLI、Claude Code、opencodeを対等な選択肢として扱う。
- 利用するツールは利用者のローカル環境で選択する。既定は環境変数 `AGENT_PROVIDER`（`codex`、`claude`、または `opencode`）で切り替え、未指定時の既定値もコードで明示する。
- ループ本体のロジックは特定ツールに依存させない。ツール固有の起動・sandbox・出力回収の差分は、単一のプロバイダアダプタ層に閉じ込める。プロバイダの追加・置換がアダプタ層の変更だけで完結する構造を維持する。

## 要求

- 各プロバイダは非対話モードで実行でき、専用worktreeの外へ書き込まないこと。秘密情報ガードhookを迂回しないこと。
- 各プロバイダで利用するモデルと推論強度（reasoning effort）は、事故的な高コスト実行を防ぐため既定値をコードでピン留めし、明示的な設定でのみ変更できること。
- OS levelのsandbox能力はツールごとに異なる。利用可能な最も強い隔離を採用し、隔離が弱いツールを使う場合はその残余リスクをドキュメントに明記すること。
- [費用ポリシー](cost.md)に従い、いずれのツールでも既存サブスクリプション契約の範囲を超える課金を発生させないこと。

## 検証

- ツールの追加・置換・既定変更時は、上記の非対話実行、worktree限定、hook非迂回、モデル/推論強度のピン留め、費用ポリシー適合を検証する。
- ドキュメントとlintは特定ツール名の直書きを前提にせず、プロバイダ切り替えの手順を維持する。
