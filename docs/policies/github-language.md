# GitHub日本語運用ポリシー

## 目的

このポリシーは、要求、実装内容、判断、検証結果を日本語で一貫して追跡できる状態を維持するため、このリポジトリのGitHub上のコミュニケーションに適用する。

## 記述言語

IssueとPRのタイトル・本文、コメント、レビューは日本語で記述する。Agentや自動化が作成する進捗報告、状態通知、確認依頼も同様とする。

次の内容は、意味、再現性、検索性を損なわないため、必要な範囲で原文を保持する。

- ソースコード、コマンド、ファイルパス、識別子、設定値
- エラーやログの原文、外部仕様の正確な引用
- 固有名詞、製品名、API名、機械可読マーカー

原文を載せる場合は、その目的や意味を日本語で併記する。

## 既存項目と検証

既存のIssueとPRに日本語化されていないタイトル、本文、コメント、レビューを発見した場合は、履歴の意味を変えない日本語に修正する。修正後は、要求、技術的制約、検証証跡、参照関係が保持されていることを確認する。

自動化がGitHubへ送る文面とAgentへの作成指示は、再現可能なテストで日本語運用を検証する。失敗を通知する文面では、機械可読マーカーや識別子を保持しつつ、失敗理由、処理への影響、安全措置および復旧方針を日本語で検証する。
