# 費用ポリシー

## 目的

このポリシーは、本プロジェクトとAgentic Loopが扱うすべての機能、設計、開発、検証、CI、配備、保守および運用に適用する。個別機能の要求や利便性より優先する。

## 許容する費用

利用料金として許容する金銭的コストは、利用者が既に契約しているCodexサブスクリプションの既存契約料金だけとする。

## 禁止する費用

Codexサブスクリプションの既存契約料金とは別に請求される、または請求される可能性がある仕組みを、導入・有効化・実行してはならない。これには次を含むが、これらに限らない。

- APIキーを使用するトークン従量課金
- GitHub Actionsなどの有料runner利用枠
- クラウド、ホスティング、ストレージ、データベース、監視などの追加サービス料金
- 有料プランへの変更、従量課金の有効化、有料リソースの作成
- 無料枠の超過によって自動的に発生する料金

## 採用条件

外部サービス、実行環境または依存機能を採用する前に、追加の金銭的コストが発生しないことを検証する。次のいずれかに該当する場合は採用しない。

- 料金体系、請求主体、無料枠または超過時の挙動を確認できない
- 利用量の増加によって自動的に課金へ移行する
- 追加費用を防ぐための強制的な上限または停止条件がない
- Codexサブスクリプションとは別のAPI課金を使用する

無料枠は、上限到達時に処理が停止し、課金へ移行しないことを検証できる場合に限り利用できる。機能停止、処理の遅延または能力の制限は、許容されない費用の発生より優先する。

料金や利用条件は変更され得るため、費用に関係する仕組みは導入時だけでなく、更新時および実行方式の変更時にも再検証する。
