# 0001: 言語非依存の最小基盤から開始する

- 状態: 採用
- 日付: 2026-08-11

## 背景

このリポジトリは、目的がまだ決まっていないアプリケーションの出発点であり、既存プロジェクトにも導入できる必要がある。現時点では、実行言語、配備先、可用性、データ保全、予算の要件がない。

## 判断

BashとMakeによる共通の検証入口、Git、CI、秘密情報の除外規則、最小のAgent原則だけを導入する。Docker、Dev Container、パッケージ管理、IaC、デプロイ、監視、バックアップは、具体的な要求から必要性を判断できるまで導入しない。

導入CLIは既存ファイルを上書きせず、競合時には変更前に停止する。これにより既存プロジェクトの方針や成果物を暗黙に破壊しない。

## 帰結

初期状態は軽量で、Gitと一般的なUnix環境だけで検証できる。アプリケーションの目的が与えられた後、再現可能な実行環境、依存管理、ビルド、配備、運用要件を選定し、この決定または新しい決定記録で根拠を残す。
